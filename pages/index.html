EPFL OpenWork Installer

Install OpenWork with EPFL inference

The installer creates your RCP API key, installs OpenCode and OpenWork, and connects them to the EPFL inference service.

Windows

Download for Windows

Portable 64-bit .exe, there is nothing to install. The system may warn about an unsigned build, choose "More info" then "Run anyway".

macOS

Download for macOS

Universal .dmg for Apple silicon and Intel. The build is unsigned, so open it from the context menu the first time.

Or run it in a terminal

curl -fsSL https://github.com/EPFL-ENAC/enac-openwork-installer/releases/latest/download/install.sh | bash

The shell installer does the same work without a desktop. It is plain bash, it needs curl and sqlite3, and it is safe to run twice.

Linux

Download for Linux x64 Download for Linux arm64

The AppImage needs libwebkit2gtk-4.1-0 and libfuse2 (libfuse2t64 on Ubuntu 24.04 and Debian 13). Make the file executable, then run it.

Or run it in a terminal

curl -fsSL https://github.com/EPFL-ENAC/enac-openwork-installer/releases/latest/download/install.sh | bash

The shell installer does the same work without a desktop. It is plain bash, it needs curl and sqlite3, and it is safe to run twice.
